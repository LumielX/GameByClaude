# BOO-TRAYAL: ผีป่วน เพื่อนแปรพักตร์ — Game Design Document

- **เวอร์ชันเอกสาร:** 1.0 (ร่างเพื่อขออนุมัติ) — 2026-10-22
- **สถานะ:** รออนุมัติจากเจ้าของเกม (LumielX)
- เครื่องหมาย **[C]** = เรื่องที่ Claude ตัดสินใจเอง (ผู้ใช้ยังไม่ได้เลือก) แก้ได้ทุกข้อ

---

## 1. เกมนี้คืออะไร และทำไม

เกมปาร์ตี้ออนไลน์ 2–8 คน มุมมองบุคคลที่ 1 เพื่อน ๆ ติดอยู่ใน **เรือนไทยโบราณที่มีผีไทยแบบตลก ๆ** ต้องช่วยกันไขปริศนา ปิดผนึก ทำพิธี แล้ววิ่งหนีออกประตูให้ทันก่อนรุ่งสาง — แต่ในทีมมี **"ร่างทรง" (Spy)** แอบป่วนอยู่ 1 คน

**เป้าหมายของเจ้าของเกม:** ทำเกมที่เล่นกับกลุ่มเพื่อนได้จริง ดาวน์โหลดจาก GitHub แตก zip แล้วเล่นได้เลย เน้นความฮา ความวุ่นวาย และการหักเหลี่ยมกันในกลุ่มเพื่อน

**ความรู้สึกที่ต้องได้:** ตลก 70 / หลอน 30 — ปกติฮาและบ้อง แต่ตอนผีไล่ต้องใจเต้นจริง กรี๊ดจริง แล้วหัวเราะทีหลัง

### 1.1 เป้าหมาย (Goals)
1. เพื่อนต่างเน็ตเข้าห้องด้วยรหัส 6 ตัวได้โดยไม่ต้องเปิดพอร์ต ไม่ต้องมีบัญชีอะไร
2. ช่วงผีไล่ต้องมันส์: ผีเข้าใกล้ = เสียงหลอน + ภาพหลอน + วิ่งไวขึ้น (Adrenaline)
3. Spy ต้องสนุกทั้งคนเล่น Spy และคนจับ — มีร่องรอยให้จับได้แบบแฟร์
4. เล่นซ้ำได้ไม่เบื่อ: ผีหลายแบบ ปริศนาสุ่ม ห้องสุ่ม modifier สุ่ม
5. ภาษาไทย (ค่าเริ่มต้น) + อังกฤษ

### 1.2 ไม่ใช่เป้าหมาย (Non-goals)
- ไม่มีจับคู่กับคนแปลกหน้า (matchmaking) — เล่นกับเพื่อนผ่านรหัสห้องเท่านั้น
- ไม่มีเซิร์ฟเวอร์กลาง (dedicated server) — เครื่อง host เป็นเซิร์ฟเวอร์
- ไม่มี host migration — host หลุด = ทุกคนกลับเมนูพร้อมข้อความ **[C]**
- Windows 64-bit เท่านั้นใน v1.0 (ไม่ทำ Mac/Linux/มือถือ) **[C]**
- ไม่มีระบบซื้อด้วยเงินจริง ไม่มีโฆษณา

### 1.3 สิ่งที่ถ้าเกิดขึ้น = ล้มเหลว แม้เกมจะทำงานได้ (Anti-goals)
- ผีโกงจนหนีไม่ได้ / ตายโดยไม่รู้ว่าตายเพราะอะไร
- Spy โดนจับง่ายเกินไปทุกครั้ง หรือไม่มีทางจับได้เลย
- คนตายเร็วต้องนั่งเบื่อ
- หลอนจนเพื่อนไม่อยากเล่นซ้ำ
- เข้าห้องไม่ได้ / หลุดแล้วเกมค้าง / เวอร์ชันไม่ตรงแล้วไม่บอก

## 2. ข้อจำกัด (Constraints)
- เจ้าของเกมไม่ใช่โปรแกรมเมอร์: ทุกอย่าง (Scene, Prefab, UI, Material, Settings) ต้องสร้างซ้ำได้ด้วย Editor script + Unity batchmode
- Asset: สร้างเอง (Blender script) หรือ CC0/ใบอนุญาตชัดเจนเท่านั้น บันทึกใน `CREDITS.md`
- ฟรีทั้งหมด (Unity Relay/Lobby/Vivox free tier พอสำหรับกลุ่มเพื่อน)
- เป้า 60 FPS บน GTX 1060 / RX 580 ที่ preset ต่ำ
- เครื่องพัฒนา: Unity 6000.6.7f1, Blender 5.2.2, RTX 5050 Laptop, RAM 16 GB

## 4. Core Loop

```
เมนู → สร้าง/เข้าห้อง (รหัส 6 ตัว) → ล็อบบี้ (แต่งตัว, Ready)
  → [คืนที่ 1..3]
      เริ่มคืน: วาร์ปเข้าเรือน (ห้องสุ่ม), สุ่ม Spy แจ้งเฉพาะคนนั้น, สุ่มผี + modifier
      ภารกิจ: ปิดผนึก N จุด (ปริศนา co-op) → ขนของพิธีกรรมไปแท่นบูชา → ทำพิธี → ประตูเปิด → หนี
      ระหว่างนั้น: ผีล่า / Spy ป่วน / ตีระฆังประชุมโหวต / ชุบเพื่อนที่ศาล
      จบคืน: หน้าสรุป (รางวัลตลก, เฉลย Spy, แต้ม/เหรียญ)
      ร้านค้าระหว่างคืน (ใช้เหรียญซื้อไอเท็ม)
  → จบเกม: อันดับรวม 3 คืน + รางวัล + ได้ "แต้มบุญ" ไปปลดล็อกชุดถาวร → กลับล็อบบี้
```

### 4.1 ตัวเลขหลัก (ค่าเริ่มต้น host ปรับได้)
| ค่า | ค่าเริ่มต้น | ปรับได้ |
|---|---|---|
| ผู้เล่น | 2–8 | จำนวนสูงสุด 2–8 |
| ความยาวคืน | 10 นาที | 8 / 10 / 12 / 15 |
| จำนวนคืน | 3 | 1 / 3 / 5 **[C]** |
| ผนึกต่อคืน **[C]** | 2 คน: 3, 3–4 คน: 4, 5–6 คน: 5, 7–8 คน: 6 | — |
| ความยาก | ปกติ | ง่าย / ปกติ / ยาก (คืนถัดไปยากขึ้นอัตโนมัติ) |

### 4.2 เงื่อนไขชนะ/แพ้ (ต่อคืน)
- **ทีมชนะ:** ทำพิธีสำเร็จ และมีลูกทีม (ไม่ใช่ Spy) ที่ยังมีชีวิตหนีออกประตูได้อย่างน้อย 1 คน ก่อนเวลาหมด **[C]**
- **Spy ชนะ:** เวลาหมดก่อนทีมหนี **หรือ** Spy ป่วนสำเร็จครบ 3 ครั้ง (2 Spy = รวมกัน 4 ครั้ง) โดยไม่ถูกโหวตไล่ (เกมไม่หยุด แต่ Spy ได้แต้มชนะทันที และทีมยังเล่นต่อเพื่อแต้มรอดได้) **[C]**
- **ทีมตายหมด** = ทีมแพ้ (Spy ชนะ)
- โหมดไม่มี Spy (co-op ล้วน): ชนะ/แพ้ตามพิธี + เวลาเท่านั้น

### 4.3 แต้ม และเงิน **[C]**
- **เหรียญ (ใช้ในเกมนี้เท่านั้น):** ได้ระหว่างคืน (ปิดผนึก +20, แบกของพิธี +10, หนีรอด +50, ทีมชนะ +50/คน, Spy ชนะ +150, จับ Spy ได้ +30/คนที่โหวตถูก) → ใช้ซื้อไอเท็มในร้านระหว่างคืน
- **คะแนนรวม:** = เหรียญที่ได้ทั้งหมด (ไม่หักเมื่อซื้อของ) ใช้จัดอันดับตอนจบเกม
- **แต้มบุญ (ถาวร เก็บในเครื่อง):** ได้ตอนจบเกม ตามอันดับ + รางวัล ใช้ปลดล็อกหมวก/สีตัว

## 5. ผู้เล่น

- **มุมกล้อง:** บุคคลที่ 1 (เห็นมือ/ไฟฉายตัวเอง เห็นตัวเพื่อนบ้อง ๆ เต็มตัว)
- **ควบคุม:** WASD เดิน, Shift วิ่ง, Space กระโดด, Ctrl ย่อ, E หยิบ/ใช้, คลิกซ้าย ใช้ไอเท็ม, คลิกขวา ผลัก/ตบเพื่อน, F ไฟฉาย, G ทิ้งของ, Q วงล้อพลัง (Spy), V กดคุย (ถ้าตั้ง Push-to-talk), Z กรี๊ด, 1–4 อีโมต, Tab ดูภารกิจ, Esc หยุด **[C]**
- **Stamina:** วิ่งเปลือง, หยุดแล้วฟื้น
- **ฟิสิกส์ตลก:** ตัวละครโยกเยก, โดนชนแรง/โดนผลัก/ตกจากที่สูง = ล้มแบบ ragdoll 1.5 วิ แล้วลุก
- **หยิบ/แบก:** ของเบาถือมือเดียว, ของหนักต้อง 2 คนจับคนละด้าน (คนเดียวลากได้ช้ามาก + เสียงดัง), ของตก = เสียงดัง ผีได้ยิน, ของพิธีกรรมบางชิ้นแตกได้ (ต้องไปเอาใหม่ที่จุดเกิด เสียเวลา) **[C]**

### 5.1 ตายแล้ว → ผีจิ๋ว + ชุบได้
- ตาย = ทิ้ง "ดวงวิญญาณ" (ลูกแก้วเรืองแสง) ไว้ที่จุดตาย ตัวเองกลายเป็น **ผีจิ๋ว** ลอยได้ ผ่านกำแพงไม่ได้ **[C]**
- ผีจิ๋วทำได้: ส่งเสียง "บู้" (cooldown 8 วิ), เคาะของเบา ๆ ให้ขยับนิดหน่อย (cooldown 15 วิ), คุยได้เฉพาะกับผีจิ๋วด้วยกัน + ได้ยินคนเป็นตามระยะ (คนเป็นไม่ได้ยินผีจิ๋ว ยกเว้นเสียงบู้) **[C]**
- **ชุบ:** เพื่อนหยิบดวงวิญญาณไปวางที่ศาลพระภูมิ (ถือค้าง 3 วิ) → คนนั้นเกิดใหม่ที่ศาล stamina เต็ม
- ผีจิ๋วโหวตในประชุมไม่ได้ **[C]**

## 6. ผี

### 6.1 State machine (ทุกตัว)
`Wander → Investigate (ได้ยิน/เห็นอะไร) → Chase → Grab → Cooldown → Wander`
- ใช้ NavMesh; ผีเร็วกว่าคนเดินแต่ช้ากว่าคนวิ่ง+Adrenaline เล็กน้อย → หนีทันถ้าตัดสินใจเร็ว
- ก่อน Chase มีสัญญาณเตือน 1 วิ (เสียงกรีด + ผีชะงัก) — ห้ามจับแบบไม่มีสัญญาณ
- Grab: ดึงตัวผู้เล่น 2 วิ (มีแอนิเมชันตลก) → ตาย; Cooldown 10 วิ ผีไม่ล่าใคร
- เลิกไล่ถ้าเป้าหมายหายจากสายตาเกิน 6 วิ **[C]**
- **ผีไม่ทำร้าย Spy ที่ยังไม่ถูกเปิดโปง** (แต่ Spy ยังต้องแกล้งวิ่งหนี) = เบาะแสให้ทีม

### 6.2 Fear Proximity (คำนวณฝั่ง client จากตำแหน่งผีที่ sync มา)
| ระยะ | เสียง | ภาพ |
|---|---|---|
| ≤ 25 m | ลมหวีด/กระซิบเบา ๆ เริ่มเข้า | — |
| ≤ 15 m | หัวใจเต้น + เสียงหลอนแบบ 3D | Vignette ขอบจอมืด, ไฟในห้องกะพริบ |
| ≤ 8 m | เสียงหลอนดังสุด | กล้องสั่นเบา ๆ, Chromatic aberration |
- ทุกชั้นเสียง cross-fade ตามระยะแบบนุ่ม ห้ามตัด
- มีตัวเลือก "ลดเอฟเฟกต์ภาพ" ใน Settings สำหรับคนเวียนหัว **[C]**

### 6.3 Adrenaline
- ผีอยู่ใน 15 m: ความเร็ววิ่ง +25% → ไล่ระดับถึง +40% ที่ ≤ 5 m
- ระหว่าง Adrenaline: stamina หมดเร็ว ×1.5
- ผีออกห่าง > 25 m นาน 3 วิ → "หอบ" ความเร็ว −20% นาน 4 วิ (มีเสียงหอบ + จอเบลอนิด ๆ)

### 6.4 รายชื่อผี (v1.0 — สุ่ม 1 ตัวต่อคืน, คืนที่ 3 ความยากสูงอาจมี 2 ตัว **[C]**)
| ผี | นิสัย / จุดอ่อน (ให้ผู้เล่นเดาเอง) |
|---|---|
| **กระสือ** (Vertical Slice) | หัวลอยไส้เรืองแสง **ได้ยินเสียงไมค์และเสียงของตก** ยิ่งกรี๊ดยิ่งโดน / กลัวแสงไฟฉายส่องตรงหน้า 2 วิ = ถอยหนี |
| **ปอบ** | หิวตลอด **ได้กลิ่นคนที่ถือของกิน**, กินของพิธีกรรมบางชิ้นทิ้ง / ล่อด้วยของกินได้ |
| **แม่นาค** | **แขนยาวจับได้ไกล** ทะลุหน้าต่าง/ใต้ถุน / เคลื่อนที่เฉพาะตอนไม่มีใครมอง |
| **กุมารทอง** | ตัวเล็ก เร็วมาก **ขโมยของจากมือแล้ววิ่งหนี** ไม่ฆ่าตรง ๆ แต่ป่วน + เรียกผีตัวอื่น / ล่อด้วยของเล่น/ขนม |

## 7. Spy ("ร่างทรง")

### 7.1 จำนวน (ผู้ใช้กำหนด 2026-10-22)
- 2–4 คน: **ไม่มี Spy** (co-op ล้วน เปิดไม่ได้)
- 5–6 คน: Spy 1 คน (host ปิดได้)
- 7–8 คน: Spy 1 คนเป็นค่าเริ่มต้น host ตั้งเป็น 2 ได้
- **สุ่มใหม่ทุกคืน** ใครก็เป็นได้ (ไม่ห้ามซ้ำ) **[C]**
- **2 Spy:** รู้จักกัน (เห็นชื่ออีกคนตอนเริ่มคืน), นับ "ป่วนสำเร็จ" รวมกัน เป้า 4 ครั้ง, ผีไม่ทำร้ายทั้งคู่จนกว่าจะถูกเปิดโปง, จับได้ 1 คน อีกคนเล่นต่อ (ผลดีของ "ไล่ถูก" ได้ทุกครั้งที่จับได้), Spy ชนะถ้ามีอย่างน้อย 1 คนยังไม่ถูกจับเมื่อครบเงื่อนไข **[C]**
- บทบาทส่งให้เฉพาะเครื่องของ Spy (server ไม่ sync บทบาทให้คนอื่น)
- Spy หลุดกลางคืน = Spy แพ้คืนนั้น ทีมเล่นต่อตามปกติ **[C]**

### 7.2 พลัง (วงล้อ กด Q ค้าง เลือก — แต่ละพลังมี cooldown ของตัวเอง)
| พลัง | ผล | cooldown **[C]** | นับเป็น "ป่วนสำเร็จ" เมื่อ |
|---|---|---|---|
| **ป่วนปริศนา** (VS) | รีเซ็ต/สลับคำตอบปริศนาที่อยู่ใกล้ (≤ 3 m) | 60 วิ | ปริศนานั้นมีความคืบหน้าอยู่ |
| **ดับไฟ** (VS) | ไฟดับทั้งโซน 10 วิ | 75 วิ | มีลูกทีมอยู่ในโซนอย่างน้อย 1 คน |
| เบาะแสปลอม | วางโน้ตรหัสผิดหน้าตาเหมือนจริง | 60 วิ | มีคนอ่านโน้ตนั้น |
| กระซิบผี | มาร์กผู้เล่น 1 คน ผีรู้ตำแหน่ง 5 วิ | 90 วิ | ผีเข้าโหมด Chase ใส่คนนั้น |
| ผีเข้าของ | ของชิ้นหนึ่งลอยปาไปโดนเพื่อน | 45 วิ | โดนเพื่อนจนล้ม |

### 7.3 ร่องรอยให้ทีมจับผิด
- หลังใช้พลัง: Spy มี **ไอเย็นออกปาก** จาง ๆ 3 วิ (คนอื่นเห็น)
- **พระเครื่อง/เครื่องสแกน** (ไอเท็ม) เรืองแสงใกล้จุดที่ถูกป่วนภายใน 20 วิ
- **กล้องโพลารอยด์** (ไอเท็ม): ถ่ายติด "เงาผี" ข้างตัว Spy ถ้าใช้พลังภายใน 15 วิ
- ผีไม่ทำร้าย Spy (ข้อ 6.1)

### 7.4 ประชุม / โหวต
- ตีระฆังที่ศาล (คนละ 1 ครั้ง/คืน, ห้ามตีระหว่างถูกผีไล่ **[C]**) → ทุกคนที่ยังมีชีวิตวาร์ปมารวมที่ลานศาล, ผีหยุด, เสียงเปลี่ยนเป็นได้ยินทั้งห้อง
- คุย 45 วิ → โหวต 15 วิ (โหวตคน หรือ "ข้าม")
- คนได้คะแนนสูงสุดโดน "ไล่ผี" ถ้า > คะแนนข้าม และไม่เสมอ **[C]**
- **ไล่ถูก (เป็น Spy):** Spy โดนสาดน้ำมนต์กระเด็นแบบตลก → กลายเป็นผีจิ๋ว (ไม่ได้รับการชุบในคืนนั้น), ผีช้าลง 20% ที่เหลือของคืน + เวลา +60 วิ **[C]**
- **ไล่ผิด:** ผีโกรธ ล่าดุขึ้น (เร็วขึ้น 20%, ได้ยินไกลขึ้น) 30 วิ + คนโดนไล่กลายเป็นผีจิ๋ว (ชุบที่ศาลได้ตามปกติ)
- **เฉลยตอนจบคืน:** สปอตไลต์ + กลองระทึก + เปิดเผย Spy + แสดงสถิติการป่วน (v1.0 ใช้ภาพนิ่ง/ไทม์ไลน์ ไม่ทำรีเพลย์วิดีโอ **[C]**)
