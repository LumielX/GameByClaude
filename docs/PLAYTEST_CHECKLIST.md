# BOO-TRAYAL — รายการทดลองเล่น (playtest)

> ใช้กับเวอร์ชัน alpha · เล่นจบแล้วช่วยกรอกส่วน **"ส่งผลกลับ"** ท้ายไฟล์ส่งให้เจ้าของเกม
> ติ๊ก `[x]` ข้อที่ผ่าน, เขียนสั้นๆ ข้างข้อที่ไม่ผ่านว่าเกิดอะไร

## 0. ก่อนเริ่ม
- [ ] ทุกคนโหลด zip เวอร์ชันเดียวกันจาก [Releases](https://github.com/LumielX/GameByClaude/releases) (เลขเวอร์ชันที่มุมหน้าแรกตรงกัน)
- [ ] แตกไฟล์แล้วเปิดได้ (ผ่านจอ SmartScreen "More info → Run anyway" และกด Allow ที่ Firewall)
- [ ] เปิด Discord/โทรคุยกันไว้สำรอง เผื่อเสียงในเกมมีปัญหา

## 1. เข้าห้อง (ต่างบ้าน ต่างเน็ต)
- [ ] เจ้าของห้องสร้างห้องได้ เห็นรหัส 6 ตัว
- [ ] เพื่อนใส่รหัสแล้วเข้าห้องได้ทุกคน (ลองทั้งเน็ตบ้าน และเน็ตมือถือ/hotspot ถ้ามี)
- [ ] ใส่รหัสผิด → ขึ้นป๊อปอัปบอกว่าหาห้องไม่เจอ
- [ ] แชทในล็อบบี้: พิมพ์แล้วกด **Enter** ส่งได้, ภาษาไทยแสดงถูก ไม่มีสระลอย/ตกหล่น
- [ ] ปุ่ม "พร้อม" ทุกคน → เจ้าของห้องเริ่มเกมได้
- [ ] ออกห้องแล้วเข้าใหม่ 2–3 รอบ ไม่ค้าง
- [ ] หน้าตั้งค่า: เปลี่ยนภาษาไทย ↔ อังกฤษ แล้วทุกหน้าเปลี่ยนตาม, dropdown ภาษาไทยอ่านออก

## 2. เสียงคุยในเกม (ต้องมีไมค์อย่างน้อย 2 คน)
- [ ] หน้าตั้งค่าขึ้นว่า "เสียงคุยเปิดอยู่"
- [ ] ยืนใกล้กันได้ยินชัด; เดินห่างออกไป (~30 เมตร) เสียงเบาลงจนเงียบ; ขึ้น "X กำลังพูด" เฉพาะคนที่อยู่ใกล้
- [ ] ตั้ง "กด V ค้างเพื่อพูด" → ไม่กด V เพื่อนไม่ได้ยิน, กด V ค้างระหว่างประชุมก็คุยได้, พิมพ์แชทที่มีตัว v ไมค์ไม่เปิด
- [ ] ตีระฆัง → ทั้งห้องได้ยินกันทุกระยะ; จบประชุม → กลับเป็นตามระยะ
- [ ] คนที่ตาย (ผีจิ๋ว) คุยกันเองได้ แต่คนเป็นไม่ได้ยิน (ยกเว้นตอนประชุม)
- [ ] ตะโกนใส่ไมค์ใกล้ผีกระสือ → ผีหันมาหา; พูดเบาๆ ผีไม่สนใจ
- [ ] เลื่อนระดับเสียงคุย → เสียงเพื่อนดัง/เบาตาม; ค่าเริ่มต้นไม่แตก
- [ ] ออกห้อง สร้างห้องใหม่ → เสียงคุยกลับมา ชื่อคนพูดถูกคน

## 3. เล่นครบ 1 เกม — ทีมล้วน (2–4 คน)
- [ ] ปิดผนึกได้ครบ: ตู้เซฟ (หาโน้ตรหัสอีกห้อง), กล่องฟิวส์ (ดึงคันโยก 2 จุดพร้อมกัน หรือวางของค้างไว้)
- [ ] ยกโกศ 2 คน + ถือกระถางธูป ไปวางแท่นบูชา → ประตูรั้วเปิด → วิ่งออกได้
- [ ] ผีกระสือ: ได้ยินเสียง (วิ่ง/กรี๊ด/ของตก), กรีดร้องเตือนก่อนไล่, ไฟฉายส่องหน้า 2 วิแล้วผีหนี
- [ ] โดนจับ → เป็นผีจิ๋ว ลอยได้ บู้ (Z) ได้; เพื่อนถือดวงวิญญาณไปศาล 3 วิ → ฟื้น
- [ ] หน้าสรุปคืน + อันดับตอนจบเกม แสดงถูก แล้วกลับล็อบบี้เอง

## 4. เล่นครบ 1 เกม — มีร่างทรง (5 คนขึ้นไป)
- [ ] ร่างทรงเห็นบทบาทตัวเองคนเดียว (คนอื่นเห็น "ลูกทีม")
- [ ] ร่างทรงป่วนปริศนา (Q) และดับไฟ (X) ได้; คนอื่นเห็นไอเย็นออกปาก
- [ ] ตีระฆัง → ทุกคนวาร์ปมาประชุม → คุย → โหวต; โหวตถูก: ผีช้าลง +60 วิ, โหวตผิด: ผีโกรธ
- [ ] จบคืนเฉลยว่าใครเป็นร่างทรง

## 5. ความลื่น
- [ ] ภาพไม่กระตุก (บอกการ์ดจอ/ซีพียู และ FPS โดยประมาณ ถ้ารู้)
- [ ] ตัวละครเพื่อนเดินลื่น ไม่วาร์ป
- [ ] ไม่มีเกมค้าง/เด้งออก (ถ้ามี บอกว่าทำอะไรอยู่ตอนนั้น)
