# คู่มือ: เปิดบริการออนไลน์ของ Unity (ทำครั้งเดียว ~10 นาที)

เกมต้องใช้ 3 บริการฟรีของ Unity: **Relay** (เชื่อมเครื่องเพื่อนโดยไม่ต้องเปิดพอร์ต), **Lobby** (ห้อง + รหัสเข้าห้อง), **Vivox** (เสียงคุย)
คุณแค่สร้างโปรเจกต์บนเว็บแล้วส่งรหัส 2 ตัวมาให้ฉัน ที่เหลือฉันใส่ในเกมเอง

> ถ้าหน้าเว็บดูไม่ตรงกับคู่มือ (Unity ชอบเปลี่ยนหน้าตาเว็บ) ให้ถ่ายรูปหน้าจอส่งมาได้เลย

## ขั้นที่ 1 — เข้าเว็บ Unity Cloud
1. เปิด https://cloud.unity.com
2. ล็อกอินด้วยบัญชี Unity เดียวกับที่ใช้ใน Unity Hub

## ขั้นที่ 2 — สร้างโปรเจกต์
1. เมนูซ้าย กด **Projects**
2. กด **Create project** (หรือ "New project")
3. ตั้งชื่อ `BOO-TRAYAL` → กดสร้าง
4. ถ้าถามเรื่องการเก็บข้อมูลเด็ก (COPPA) ให้เลือก **No** (เกมไม่ได้ทำมาเพื่อเด็กอายุต่ำกว่า 13 ปี)

## ขั้นที่ 3 — เปิด Relay และ Lobby
1. ในโปรเจกต์ BOO-TRAYAL เมนูซ้ายหา **Products** หรือ **Multiplayer**
2. หา **Relay** → กด **Get started / Enable** → ถ้ามีหน้าขอให้ตั้งค่าเพิ่ม กด **Skip/Next** ไปจนจบได้
3. หา **Lobby** → ทำเหมือนกัน
4. ถ้ามีหน้าถามบัตรเครดิต: Relay/Lobby มีโควตาฟรีที่พอสำหรับกลุ่มเพื่อนแน่นอน **ไม่ต้องใส่บัตร** ถ้าบังคับใส่บัตร ให้หยุดแล้วบอกฉันก่อน

## ขั้นที่ 4 — เปิด Vivox (เสียงคุย)
1. เมนูซ้ายหา **Vivox** (อาจอยู่ใต้ "Communication" หรือ "Voice and Text Chat")
2. กด **Get started / Set up** → ทำตามขั้นจนจบ (ใช้ค่าเริ่มต้นทั้งหมด)
3. ถ้าถามว่า "Test" หรือ "Production" environment ให้ใช้ค่าเริ่มต้น (production)

## ขั้นที่ 5 — คัดลอกรหัส 2 ตัวส่งให้ฉัน
1. ในโปรเจกต์ไปที่ **Project settings** (รูปเฟือง)
2. คัดลอก **Project ID** (หน้าตาแบบ `1a2b3c4d-....`)
3. คัดลอก **Organization ID** (อยู่ในหน้า Organization settings หรือแสดงคู่กันในหน้าเดียวกัน)
4. ส่งทั้งสองตัวมาในแชท

> Project ID และ Organization ID **ไม่ใช่รหัสลับ** (เหมือนเลขที่บ้าน ไม่ใช่กุญแจ) ส่งในแชทได้ปลอดภัย
> **ห้ามส่ง**: รหัสผ่าน, Service Account key, Secret key ใด ๆ — เกมนี้ไม่ต้องใช้
