BOO-TRAYAL — ผีป่วน เพื่อนแปรพักตร์ (เวอร์ชันทดลอง alpha)
=====================================================

เกมผีไทยตลกหลอนเล่นกับเพื่อน 2–8 คน: ช่วยกันปิดผนึก ทำพิธี แล้ววิ่งหนีผีกระสือ
ให้ทันก่อนรุ่งสาง — แต่ระวัง เพื่อนบางคนอาจเป็นร่างทรงแอบป่วน

เริ่มเล่น
--------
1. แตกไฟล์ zip ทั้งโฟลเดอร์ไว้ที่ไหนก็ได้ (อย่าเปิดจากใน zip ตรงๆ)
2. ดับเบิลคลิก BOO-TRAYAL.exe
3. ถ้า Windows ขึ้นจอสีฟ้า "Windows protected your PC" (ภาษาไทย: "Windows ได้ป้องกันพีซีของคุณ")
   ให้กด "More info" (ข้อมูลเพิ่มเติม) แล้วกด "Run anyway" (เรียกใช้ต่อไป)
   (เกมยังไม่ได้ซื้อใบรับรองดิจิทัล ไม่ใช่ไวรัส)
   ถ้าขึ้นว่า "Smart App Control blocked" และไม่มีปุ่มให้กดต่อ: Windows 11 เปิด Smart App Control อยู่
   ซึ่งบล็อกเกมที่ไม่ได้เซ็นใบรับรองทุกเกม — ปิดได้ที่ Windows Security → App & browser control →
   Smart App Control (ปิดแล้วเปิดกลับไม่ได้ถ้าไม่ติดตั้ง Windows ใหม่ ตัดสินใจเองนะ)
4. ถ้ามีหน้าต่าง Firewall ถาม ให้กด "Allow" (อนุญาต) เพื่อให้เล่นออนไลน์ได้

เล่นกับเพื่อน
-----------
- คนสร้างห้อง: เล่น → สร้างห้อง → ส่ง "รหัสห้อง 6 ตัว" ให้เพื่อน
- คนเข้าห้อง: เล่น → ใส่รหัสห้อง → เข้าห้อง
- ทุกคนต้องใช้เกมเวอร์ชันเดียวกัน (ดูเลขเวอร์ชันที่มุมหน้าแรก)
- เสียงคุยในเกมเปิดเองในห้องออนไลน์ ตั้ง "กด V ค้างเพื่อพูด" ได้ในหน้าตั้งค่า
- อยากซ้อมก่อน: เล่น → เริ่มซ้อม (ไม่ต้องใช้เน็ต)

ปุ่ม
----
WASD เดิน · Shift วิ่ง · Space กระโดด · Ctrl ย่อ · E หยิบ/ใช้ · คลิกซ้าย ขว้าง · G วาง
คลิกขวา ผลัก · F ไฟฉาย · Z กรี๊ด (ผีจิ๋ว: บู้) · V กดคุย · Esc หยุด

BOO-TRAYAL (alpha) — English
============================

A funny-spooky Thai ghost party game for 2–8 friends: close the seals, perform the ritual and
outrun the Krasue before dawn — but one of your friends may be possessed and sabotaging you.

Start
-----
1. Extract the whole zip folder anywhere (do not run it from inside the zip).
2. Double-click BOO-TRAYAL.exe.
3. If Windows shows "Windows protected your PC", click "More info", then "Run anyway"
   (the game is not code-signed yet).
   "Smart App Control blocked" with no way to continue means Windows 11 Smart App Control is on; it
   blocks every unsigned game (Windows Security -> App & browser control -> Smart App Control; once off it
   cannot be turned back on without reinstalling Windows, so decide for yourself).
4. If the firewall asks, click "Allow" so online play works.

Play with friends
-----------------
- Host: Play → Create room → send your friends the 6-character room code.
- Join: Play → enter the code → Join.
- Everyone needs the same version (shown on the title screen).
- Voice chat turns on by itself in online rooms; Settings has "Hold V to talk".
- Practice alone: Play → Start practice (no internet needed).

Keys
----
WASD move · Shift run · Space jump · Ctrl crouch · E grab/use · Left click throw · G drop
Right click push · F flashlight · Z scream (mini ghost: boo) · V push-to-talk · Esc pause
Spy: Q sabotage a nearby puzzle · X black out a zone
