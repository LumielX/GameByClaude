# BOO-TRAYAL — ผีป่วน เพื่อนแปรพักตร์

> เกมผีไทยตลกหลอน เล่นออนไลน์กับเพื่อน 2–8 คน · สถานะ: **alpha** (ทดลองเล่น)

ช่วยกันปิดผนึก ขนโกศกับกระถางธูปไปแท่นบูชาข้างศาลพระภูมิ แล้ววิ่งหนีผีกระสือออกประตูรั้วให้ทันก่อนรุ่งสาง — แต่ระวัง ถ้าเล่น 5 คนขึ้นไป เพื่อนบางคนอาจเป็น **ร่างทรง** ที่แอบป่วนอยู่ ตีระฆังเรียกประชุม คุยกัน แล้วโหวตไล่ให้ถูกคน

## ดาวน์โหลดและติดตั้ง
1. ไปที่หน้า [Releases](https://github.com/LumielX/GameByClaude/releases) แล้วโหลดไฟล์ `BOO-TRAYAL-v…-win64.zip` ของเวอร์ชันล่าสุด
2. แตกไฟล์ zip ทั้งโฟลเดอร์ไว้ที่ไหนก็ได้ (อย่าเปิดจากใน zip ตรงๆ)
3. ดับเบิลคลิก `BOO-TRAYAL.exe`
   - ถ้าขึ้นจอสีฟ้า **"Windows protected your PC"** ให้กด **More info** แล้ว **Run anyway** (เกมยังไม่ได้เซ็นใบรับรอง)
   - ถ้า Firewall ถาม ให้กด **Allow** เพื่อเล่นออนไลน์ได้

**เครื่องที่ใช้ได้:** Windows 10/11 64 บิต, การ์ดจอที่รองรับ DirectX 11/12, อินเทอร์เน็ต (สำหรับเล่นออนไลน์), ไมค์ไม่บังคับ

## เล่นกับเพื่อน
- **คนสร้างห้อง:** เล่น → สร้างห้อง → ตั้งจำนวนคน/ความยาวคืน/ร่างทรง → ส่ง **รหัสห้อง 6 ตัว** ให้เพื่อน
- **คนเข้าห้อง:** เล่น → ใส่รหัสห้อง → เข้าห้อง (เล่นต่างเน็ต ต่างบ้านได้)
- ทุกคนต้องใช้ **เวอร์ชันเดียวกัน** (ดูที่มุมหน้าแรก)
- เสียงคุยในเกมเปิดเองในห้องออนไลน์: คุยกันตามระยะ, ตอนประชุมได้ยินทั้งห้อง, ผีจิ๋วคุยกันเอง — ตั้ง "กด V ค้างเพื่อพูด" ได้
- อยากลองก่อน: เล่น → **เริ่มซ้อม** (ออฟไลน์ ไม่มีร่างทรง)

| ปุ่ม | ทำอะไร |
|---|---|
| WASD / Shift / Space / Ctrl | เดิน / วิ่ง / กระโดด / ย่อ |
| E | หยิบ / ใช้ |
| คลิกซ้าย / G / คลิกขวา | ขว้าง / วาง / ผลัก |
| F | ไฟฉาย (ส่องหน้าผี 2 วิ ผีหนี) |
| Z | กรี๊ด (ผีจิ๋ว: บู้) |
| V | กดคุย (ถ้าตั้งไว้) |
| Q / X | ร่างทรง: ป่วนปริศนาใกล้ตัว / ดับไฟทั้งโซน |
| Esc | หยุดเกม |

## English

**BOO-TRAYAL** is a funny-spooky Thai ghost party game for 2–8 friends online. Status: **alpha**.

Close the seals, carry the urn and incense pot to the shrine altar, and outrun the Krasue through the gate before dawn. With 5+ players a friend may secretly be the **Spy**. Ring the bell to call a meeting and vote them out.

**Install:**
1. Download `BOO-TRAYAL-v…-win64.zip` from [Releases](https://github.com/LumielX/GameByClaude/releases) and unzip it.
2. Run `BOO-TRAYAL.exe`. On a SmartScreen warning, click **More info → Run anyway**.
3. Allow the firewall prompt.

The game needs Windows 10/11 64-bit with a DirectX 11/12 GPU.

**Play:**
- One player picks *Play → Create room* and shares the 6-character code.
- The others pick *Play → Join* and enter it. This works across different networks.
- Everyone needs the same version.

Voice chat is proximity-based; in meetings, the whole room hears everyone. *Settings* has push-to-talk (hold V).

**Keys:**
- WASD move · Shift run · Space jump · Ctrl crouch
- E grab/use · Left click throw · G drop · Right click push
- F flashlight · Z scream (mini ghost: boo) · V talk · Esc pause
- Spy: Q sabotage · X blackout

**Bugs:** open an [issue](https://github.com/LumielX/GameByClaude/issues) and attach `%USERPROFILE%\AppData\LocalLow\LumielX\BOO-TRAYAL\Player.log`.

**Build from source:** you need Unity 6000.6.7f1. Every scene and prefab is generated by the editor builders. Run `tools/unity/build-windows.ps1 -Zip` with the Editor closed.
